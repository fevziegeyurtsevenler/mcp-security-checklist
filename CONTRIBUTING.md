# Contributing

Thanks for helping improve this resource. Contributions welcome:

- **Corrections & updates** — outdated items, broken links, wrong mappings.
- **New entries** — keep them accurate, useful and maintained; cite the primary source.
- **Translations & clarity** — this is a bilingual (EN/TR) project; better wording helps.

Please keep claims honest (no "first/best"), map to OWASP LLM Top 10 / MITRE ATLAS where
relevant, and open a PR describing what you changed and why. Every external link should resolve.
